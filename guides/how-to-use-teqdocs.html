How to Use TeqDocs Effectively

Guide · Updated July 2026 · ~8 min read

TeqDocs is a lightweight document reader and light editor that runs in your browser. It supports Markdown, Microsoft Word (.docx), and PDF files. The design priority is simple: open a document quickly, read it comfortably, keep your place, and keep working even when the network is unreliable.

This guide walks through the features that matter most for everyday use — whether you are a student reading course materials, a professional reviewing reports, or someone who simply wants a clean place to keep notes and reference files.

1. Opening documents

You can open files in three main ways:

  • From your device — Use the open/file picker to select Markdown, .docx, or PDF files stored on your phone or computer.
  • From cloud storage — TeqDocs can work with files from services such as Google Drive, OneDrive, or Dropbox when you grant access. This is useful when the same documents need to be available across devices.
  • Recent files — Files you have opened before appear in the sidebar so you can return to them without searching again.
Tip: On mobile, “Add to Home Screen” turns TeqDocs into an app-like experience. Once installed, it loads faster and can be used more comfortably offline.

2. Reading and navigation

When a document is open, the main area focuses on the text. A sidebar gives you quick access to:

  • The table of contents (generated from headings when available)
  • Your bookmarks and highlights
  • File list and recent documents

For long PDFs and Word documents, the table of contents is especially helpful. Jumping by heading is faster than scrolling page by page, particularly on a phone.

Bookmarks and highlights

Mark important passages so you can return to them later. Bookmarks act as personal anchors inside a document. Highlights let you emphasise key sentences or definitions. Both stay associated with the file so they are available the next time you open it on the same device.

3. Working offline

One of the design goals of TeqDocs is resilience on weak connections. Once a file has been opened and is available locally, you can continue reading it without a constant internet connection. Changes you make (bookmarks, highlights, light edits where supported) are kept on the device.

This is particularly useful in places where data is expensive or coverage is intermittent. You can download or open the materials you need while you have connectivity, then study or work later without worrying about the network.

4. Ambient sounds for focus

TeqDocs includes optional ambient soundscapes — rain, ocean, forest, lo-fi, and white noise. Many people find that a steady, non-distracting background sound makes it easier to concentrate, especially in noisy environments or when studying for long periods.

You can start a sound while reading and leave it running in the background. Volume is adjustable so it stays in the background rather than competing with the text. There is a separate guide that explains why these sounds help and how to use them effectively.

5. Supported formats and practical advice

Markdown (.md)

Markdown is excellent for notes, technical writing, and documents you want to keep lightweight and future-proof. TeqDocs renders headings, lists, code blocks, and links cleanly. If you write a lot of notes, Markdown is often the most pleasant format to work with.

Word (.docx)

Word documents remain the standard in many schools, offices, and organisations. TeqDocs can open them for reading and basic review. For heavy editing you will still want a full word processor, but for reading and light annotation TeqDocs keeps the experience fast.

PDF

PDFs are ideal when layout must be preserved (forms, official documents, textbooks, research papers). TeqDocs uses a dedicated PDF engine so pages render consistently. Because PDFs can be large, opening them on a slow connection may take a moment the first time; afterwards they are available from local storage.

6. Tips for students and professionals

  • Open the week’s reading materials while you have good connectivity, then study later offline.
  • Use bookmarks at the start of each major section so revision is faster.
  • Combine TeqDocs with TeqXus AI: ask the AI questions about concepts while you have the source document open in another tab or window.
  • Keep a simple naming convention for files (for example “CourseName-Week03-Notes.md”) so the recent-files list stays usable.
  • On shared or public computers, remember that local storage belongs to that browser profile. Prefer cloud links or personal devices for sensitive material.

7. Privacy and data

Documents you open stay on your device unless you deliberately use a cloud connection. TeqDocs does not upload the content of your files to TeqXus servers for normal reading. For full details see the Privacy Policy.

Getting started

Open TeqDocs, choose a file you already have, and explore the sidebar. The interface is intentionally minimal so the document stays the focus. Once you have used bookmarks and the table of contents a few times, the workflow becomes natural.
